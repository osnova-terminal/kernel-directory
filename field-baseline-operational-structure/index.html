ARTICLE I — READINGS

§1.1 All Operators are evaluated across three primary indices:

>> BRN (Brain)
>> FRM (Frame)
>> NRV (Nerve)

§1.2 A Reading is defined as: a quantified measure of operator stability and capability within material conditions.

§1.3 — FUNCTIONAL DOMAINS

BRN governs: interpretation, pattern recognition, anomaly detection.

FRM governs: physical execution, spatial control, interaction with material systems.

NRV governs: stress tolerance, internal regulation, resistance to distortion.

§1.4 — ALLOCATION Operators are assigned a total of 36 points across Readings. Constraints:

>> Minimum per Reading: 8
>> Maximum per Reading: 16

§1.5 Readings are not static. Degradation occurs under:

>> strain
>> Extended exposure to Higgs Field Nullification Tools
>> Knot usage
>> Hex usage
>> [REDACTED]
ARTICLE II — PALE STRUCTURE

§2.1 Each Reading produces an associated Pale value.

§2.2 — CALCULATION Pale = ⌈Reading ÷ 2⌉, rounded up.

§2.3 The Pale is defined as: the measurable interface layer between the material condition and the static field.

§2.4 — FUNCTION

>> The Pale absorbs damage first
>> When Pale reaches 0, degradation transfers to the Reading
>> Reading degradation → reduced procedural success, increased instability

§2.5 Operators with reduced Pale exhibit:

>> delayed response
>> perceptual distortion
>> partial desynchronization

Observed escalation is recorded under Case [REDACTED].

>> PALE INTEGRITY COMPROMISED
>> TRANSFER TO CORE READING
ARTICLE III — STATIC FIELD

§3.1 The Static is defined as: a non-material field enveloping and permeating all known space.

§3.2 The Operant recognizes that: the material world is not continuous. It is contained.

§3.3 The state known as Kasparov Soviet exists as: a localized material pocket surrounded by Static.

§3.4 Static exhibits the following properties:

>> non-linear interaction with causality
>> resistance to direct measurement
>> influence over ESP manifestation

§3.5 Encroachment events, where Static pressure increases within material space, are logged under Far-Field and Near-Field Images at the OSNOVA's Astrophysics Department.

>> STATIC PRESSURE ELEVATED
>> CONTAINMENT HOLDING
ARTICLE IV — PROCEDURES

§4.1 A Procedure is defined as: a standardized operational action performed by an Operator under evaluation.

§4.2 Procedures are the only recognized method of: resolving action, measuring outcome, recording operator performance.

§4.3 — EXECUTION Run Procedure: [Designation]. Resolution:

>> Unstamped → 1d20 + relevant Reading
>> Stamped → 2d20 (retain highest) + relevant Reading

§4.4 Each Procedure is linked to a single Reading (BRN, FRM, or NRV). Assignment is determined by context.

>> PROCEDURE INITIATED
>> RESULT PENDING

Classification criteria remain incomplete.

ARTICLE VI — STAMPING

§6.1 Stamping is defined as: the formal authorization of an Operator to execute a Procedure under controlled conditions.

§6.2 A Stamp indicates:

>> verified exposure
>> procedural familiarity
>> acceptable reliability threshold

§6.3 — EFFECT Stamped Operators roll 2d20, retain the highest result, and apply the relevant Reading.

§6.4 Unstamped Operators roll 1d20 and apply the relevant Reading.

§6.5 Stamping is:

>> assigned
>> recorded
>> revocable

§6.6 Unauthorized execution of Procedures without Stamp authorization may result in:

>> misresolution
>> Reading strain
>> performance review
>> STAMP STATUS VERIFIED
>> EXECUTION AUTHORIZED
ARTICLE VII — INVENTORY CAPACITY

§7.1 All Operators are assigned a fixed inventory capacity at baseline.

§7.2 Inventory capacity defines the number of elements an Operator may carry into a Case File.

§7.3 Each element occupies one (1) slot unless specified otherwise. Elements include, but are not limited to:

>> Knots
>> Hexes
>> Modules
>> Issued equipment

§7.4 Baseline capacity is limited. Operators are required to make selection tradeoffs during Preparation.

§7.5 Exceeding assigned capacity is not permitted under standard conditions.

§7.6 Inventory capacity may be expanded through:

>> Authorization
>> Specialization
>> Operational clearance
>> External support

§7.7 Expanded capacity remains regulated and subject to revocation.

§7.8 Increased capacity reduces selection pressure and alters operational profile. Such deviations are monitored.

>> CAPACITY LOCKED
>> OVERFLOW DENIED

ARTICLE I — CASE FILE DESIGNATION

§1.1 All OSNOVA operations are conducted under a designated Case File.

§1.2 A Case File defines scope, objective, and operational boundaries.

§1.3 Operators are bound to the Case File upon Brief issuance.

ARTICLE III — BRIEF

§3.1 The Brief establishes the initial operational frame.

§3.2 The Brief includes:

>> Incident summary
>> Location
>> Known actors and anomalies
>> Assigned objective

§3.3 Information contained within the Brief is incomplete by design.

ARTICLE IV — PREPARATION

§4.1 Upon Brief conclusion, operators enter Preparation.

§4.2 During Preparation, operators:

>> Select Module Configuration
>> Hew Knots
>> Grave Hexes

§4.3 No active engagement occurs during Preparation.

ARTICLE V — ZONES

§5.1 All operations occur within defined Zones.

§5.2 A Zone contains:

>> Active variables
>> Environmental conditions
>> Subjects and elements

§5.3 Each Zone carries a concealed metric: Static Load.

ARTICLE VI — STATIC LOAD

§6.1 Static Load measures Static pressure within material space.

§6.2 Static Load increases through:

>> Hex execution
>> Knot execution
>> Routine assembly or deployment
>> Failed Procedures
>> Forced progression or prolonged presence

§6.3 Elevated Static Load manifests as:

>> Perceptual distortion
>> Environmental instability
>> Behavioral deviation
>> Execution interference

§6.4 Static Load values are not disclosed to operators by their handlers.

ARTICLE VII — INVESTIGATION

§7.1 Operators conduct Procedures within a Zone.

§7.2 Procedure resolution is:

>> Unstamped → 1d20 + relevant Reading
>> Stamped → 2d20 (retain highest) + relevant Reading

§7.3 Outcomes:

>> Resolved — clear information, procedure successful
>> Partial — incomplete or distorted information
>> Null — complication and/or Static Load increase

§7.4 Procedures define progression within a Zone.

ARTICLE VIII — CASE BUILDING

§8.1 Operators establish:

>> Cause
>> Responsible agent
>> Intended resolution

§8.2 Case validity is internally classified as File Integrity.

§8.4 File Integrity affects outcome. States are detailed below.

ARTICLE IX — RESOLUTION

§9.1 A Case File resolves through:

>> Containment
>> Extraction
>> Direct Confrontation
>> Prosecution

§9.2 Resolution is operator-directed within Brief constraints.

ARTICLE X — DIRECT CONFRONTATION PROTOCOL

§10.1 Confrontation is a Zone under elevated Static Load.

§10.2 Response order is determined by 1d20 + NRV.

§10.3 Each operator performs:

>> One Full Action
>> OR Two Half-Actions
>> Movement within reason
ARTICLE XI — DAMAGE RESOLUTION

§11.1 Damage is resolved through Hit Tiers, detailed below.

§11.2 Damage applies: Pale → Reading.

§11.3 Some effects bypass Pale.

ARTICLE XVI — DEBRIEF

§16.1 Upon completion:

>> Full case truth is disclosed
