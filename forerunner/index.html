MODULE OPERATION DIRECTIVES

Allotment

Forerunners do not roll during Briefing. They select Modules directly from the table. One Module takes up one inventory slot per Unit Size (1U, 2U, 3U, etc.). Modules are fixed, known, and issued. No randomness. No emergence. Configuration is always intentional, geared towards operator specialization.


Module Execution

Each Module is used as a Half-Action. Module output is discrete, it does not scale on its own.


Routines

Routines are constructed in the field by connecting Modules. Connecting two Modules requires a Full Action. Each connection builds a chain.

>> 2 Modules → 1 connection → 1 Full Action
>> 3 Modules → 2 connections → 2 Full Actions

Routines depend on module ports.

>> M ports output signal.
>> F ports receive signal input.
>> P ports are passive. They do not connect directly into the signal flow but must be attached to the routine to alter the signal.

EXECUTION MODEL

>> Modules → fast, limited
>> Routines → slow, powerful

Interruption

If the Forerunner is:

>> displaced
>> interrupted
>> forced to react

Routine construction may:

>> stall
>> misalign
>> fail

Assembly requires continuity.

DESIGN INTENT

Forerunners are not reactive. They are preparatory, calculating, positional and procedural. They do not spike output instantly, they must build toward it.

Tactical Consequence

In direct confrontation:

>> Early turns → weak presence
>> Mid turns → partial assembly
>> Late turns → full Routine execution

Field Directive

Avoid direct engagement without preparation.

>> Use Zones
>> Control space
>> Buy time
